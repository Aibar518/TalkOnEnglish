# 🇬🇧 TalkOnEnglish — Web Application for Learning English

**TalkOnEnglish** — это интерактивное веб-приложение для эффективного и интересного изучения английского языка. Проект включает в себя все ключевые аспекты освоения языка: от определения уровня и изучения грамматики до практики аудирования, чтения и общения с ИИ-помощником.

🚀 **Live Demo:** [TalkOnEnglish App](https://aibar518.github.io/TalkOnEnglish/)

---

## 🌟 Основные возможности

* 📊 **Тест на определение уровня (Level Tests):** Проверка текущих знаний и подбор соответствующего уровня сложности.
* 📚 **Грамматика (Grammar):** Понятные правила и интерактивные упражнения для закрепления.
* 🎧 **Аудирование (Listening):** Практика восприятия английской речи на слух.
* 📖 **Чтение и Истории (Reading & Stories):** Чтение текстов разного уровня сложности с параллельным переводом и разбором.
* 🎙️ **Аудиокниги (Audiobooks):** Прослушивание книг на английском для погружения в языковую среду.
* 🤖 **ИИ-Ассистент (AI Service):** Интерактивный помощник для практики диалогов и ответы на вопросы по грамматике.

---

## 🛠️ Технологический стек

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Data Storage:** JSON (для хранения тестов, историй и аудиофайлов)
* **API / AI:** Custom AI Integration (`ai-service.js`)
* **Hosting:** GitHub Pages
